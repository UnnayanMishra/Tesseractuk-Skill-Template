# Tesseractuk-Skill-Template

Per-project scaffolding for the Claude Code workflow. This repo does NOT hold the
knowledge base or the skill library — only the template shape to bootstrap a new
project with.

- `CLAUDE.md.template` — copy to `<project>/CLAUDE.md`
- `docs/*.template` — copy each to `<project>/docs/*.md` (drop the `.template`
  suffix): `architecture.md`, `decisions.md`, `tasks.md`, `context.md`,
  `brainstorm.md`, `design.mmd`
- `skills/example-skill/SKILL.md` — the shape to copy when scaffolding a new skill

The searchable skill library and shared knowledge base live in the separate `Skills`
repo (github.com/UnnayanMishra/Skills), cloned locally at
`/Users/unnayanmishra/Documents/Skills/knowledge-base/`.

See this repo's own `CLAUDE.md` for the full rules.
